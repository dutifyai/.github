## Dutify

**The AI context layer for modern work.**

Four connected products on one shared foundation:

| | |
|---|---|
| **[Dutify Cloud](https://dutify.cloud)** | Project management — tasks, projects and team workflows |
| **[Codexum](https://codexum.ai)** | Wiki, docs and help centers |
| **[Roadmarq](https://roadmarq.ai)** | Requests, bugs, voting and a public roadmap |
| **[Dutify Hub](https://hub.dutify.ai)** | AI meeting notes, and an AI coworker that acts across your tools |

Teams work on the shared context directly; AI agents reach the same information
through the API and MCP connectors — so agents act on what your team actually
knows, rather than a stale copy of it.

The repositories here are the Claude Code skills for our HTTP APIs, plus Dutify
Desktop releases.
